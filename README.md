# Booklist is a simple console-based book tracking application built with C# and .NET 9.
### It allows users to keep track of books they are reading, have completed, or plan to read, with all data stored locally using SQLite and Entity Framework Core.
### The application automatically creates and manages its database on first run, making setup easy and hassle-free.

## Features

- 📖 View all tracked books in a clean console interface

- ➕ Add new books with validation

- ✏️ Edit existing book details:

  - Title

  - Author

  - Page count

  - Reading status

- ❌ Remove books from the list

- 💾 Local SQLite database generated automatically

- 🧠 Input validation with custom exceptions

## How to run

1. Clone the repository:

    ``` git clone https://github.com/Deeeiw/Booklist.git ```
2. Navigate to the project folder:
   
    ``` cd booklist-test ```
4. Run the program:
   
    ``` dotnet run ```
